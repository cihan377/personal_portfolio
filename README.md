## 🎯 Proje Hakkında

Bu web sitesi, kişisel yeteneklerimi, projelerimi ve deneyimlerimi profesyonel bir şekilde sunmak için tasarlanmıştır. Modern tasarım, responsive yapı ve yüksek performans ile oluşturulmuştur.

### ✨ Özellikler

- ✅ **Responsive Tasarım** - Tüm cihazlarda mükemmel görünüm
- ✅ **Modern UI** - Tailwind CSS ve shadcn/ui ile tasarlanmış
- ✅ **Hızlı Performans** - Vite ile optimize edilmiş
- ✅ **SEO Uyumlu** - Arama motorlarında iyi sıralanma
- ✅ **Erişilebilir** - WCAG standartlarına uygun
- ✅ **Koyu/Açık Tema** - Tema değiştirme seçeneği

## 🚀 Kurulum

### Ön Koşullar
- Node.js v18 veya üzeri
- pnpm (veya npm)

### Adımlar

1. **Repository'yi Clone Et**
```bash
git clone https://github.com/cihan377/personal_portfolio.git
cd personal_portfolio
```

2. **Bağımlılıkları Yükle**
```bash
pnpm install
```

3. **Geliştirme Sunucusunu Başlat**
```bash
pnpm dev
```

4. **Tarayıcıda Aç**
```
http://localhost:5173
```

## 🔧 Özelleştirme

### Bilgilerinizi Güncelleme

1. **Hero Bölümü:** `client/src/components/Hero.tsx`
   - İsim ve özet metni değiştirin

2. **About Bölümü:** `client/src/components/About.tsx`
   - Hakkımda metni güncelleyin

3. **Projeler:** `client/src/components/Projects.tsx`
   - Proje bilgilerini ekleyin/değiştirin

4. **Yetenekler:** `client/src/components/Skills.tsx`
   - Yetenek listesini güncelleyin

5. **İletişim:** `client/src/components/Contact.tsx`
   - İletişim bilgilerinizi ekleyin

### Renkleri Değiştirme

`client/src/index.css` dosyasında CSS değişkenlerini güncelleyin:

```css
:root {
  --primary: #yeni-renk;
  --accent: #yeni-renk;
  --background: #yeni-renk;
  --foreground: #yeni-renk;
}
```

## 🌐 Deployment

### Vercel (Önerilir)

1. [vercel.com](https://vercel.com) adresine git
2. GitHub hesabınla giriş yap
3. Repository'yi import et
4. Otomatik deploy olur

### Netlify

1. [netlify.com](https://netlify.com) adresine git
2. GitHub hesabınla bağlan
3. Repository'yi seç
4. Build ayarlarını yapılandır
5. Deploy et

### GitHub Pages

1. Repository ayarlarına git
2. GitHub Pages'i etkinleştir
3. `gh-pages` branch'ini seç
